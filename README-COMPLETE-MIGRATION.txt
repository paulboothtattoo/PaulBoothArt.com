PAULBOOTHART.COM — ACTUAL IMAGE MIGRATION

This package contains the supplied PaulBoothArt.com site plus a one-click
Windows migration tool. It found 106 unique Squarespace image URLs.

WHAT THIS VERSION DOES

1. Downloads the actual image files into:

   content\images

2. Rewrites every exact Squarespace image URL to:

   /content/images/<filename>

3. Audits the whole site for remaining Squarespace references.

4. Creates the actual completed deployment ZIP one folder above:

   PaulBoothArt-INDEPENDENT-COMPLETE.zip

RUN

1. Extract this ZIP into a new folder.
2. Double-click RUN-COMPLETE-MIGRATION.bat.
3. Wait until it says SUCCESS.
4. Open SQUARESPACE-ASSET-AUDIT.json and confirm it says PASS.
5. Deploy PaulBoothArt-INDEPENDENT-COMPLETE.zip.

Do not cancel Squarespace before the migration reports SUCCESS and the site
has been visually tested after deployment.
